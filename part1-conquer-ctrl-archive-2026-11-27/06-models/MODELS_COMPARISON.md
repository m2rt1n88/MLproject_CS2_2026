# 四个模型：朴素贝叶斯 / 逻辑回归 / 随机森林 / KNN

**同一份数据、同一批 41 列特征、同一条时间切分、同一套镜像扩增与样本权重。**
唯一变化的是分类器本身。逻辑回归分支逐场复现发布版 M2（最大概率差 3.3e-16），说明四者的对照条件一致。

> 已知不完全可比之处：`KNeighborsClassifier` 不接受 `sample_weight`，所以 **KNN 用不了 365 天时间衰减权重**，其余三个模型都有。这一点在对比 KNN 时要记住。

## 1. 结果

| 模型 | val 准确率 | val log loss | val Brier | val ECE | 覆盖 50% 时准确率 |
|---|---:|---:|---:|---:|---:|
| 朴素贝叶斯 | 63.47% | 1.5052 | 0.2980 | 0.2639 | 71.75% |

| KNN | 62.75% | 0.6396 | 0.2246 | 0.0245 | 70.53% |

参照：每场都报 50% 的 log loss = **0.6931**。

按 OOF log loss 选中 **k=135**。k 太小（5）时邻居里常常一个正例都没有，概率直接给 0 或 1，log loss 会爆到 1.9 以上；k 太大则退化成「平均主义」，概率全部挤在 0.5 附近，区分度下降。

## 3. 这几个数字最重要的一件事

- 准确率：63.47% / 63.26% / 64.02% / 62.75%，极差只有 1.27 个百分点——**在 1,968 场的抽样误差（约 1pp）内，分不出高低。**
- log loss：1.5052 / 0.6338 / 0.6357 / 0.6396——**朴素贝叶斯是最差者的 2.4 倍。**
- ECE：0.2639 / 0.0246 / 0.0310 / 0.0245。

**准确率这一列几乎没有信息量；log loss 和 ECE 才能把四个模型分开。**

## 4. 四个模型的原理（各三句）

### 朴素贝叶斯

1. 用贝叶斯公式 `P(胜|特征) ∝ P(特征|胜)·P(胜)`，谁的后验大概率高就判谁。
2. 假设**给定胜负后各特征互相独立**，于是 41 维联合分布拆成 41 个一维分布。
3. 这个假设在真实数据上几乎一定不成立——相关特征被当成独立证据重复累加，概率被推到 0/1。

### 逻辑回归

1. 假设胜负的对数几率是特征的线性函数 `log(p/(1-p)) = w·x`，再用 sigmoid 压回 0–1。
2. 用极大似然（等价于最小化交叉熵）估权重，加 L2 正则控制过拟合。
3. 它直接对概率建模、训练目标就是 log loss，所以输出的概率天然可信。

### 随机森林

1. 训练很多棵决策树，每棵用 bootstrap 采样得到的数据子集、每次分裂只看随机一部分特征。
2. 预测时把所有树的概率取平均——单棵树方差大，平均之后方差被压下去（bagging）。
3. 擅长非线性与交互，但平均概率不等于校准好的概率。

### KNN（K-Nearest Neighbors）

1. 不做任何训练：把训练样本全部记下来，来一个新样本就找**距离最近的 k 个邻居**，看他们里赢的比例。
2. 它没有任何参数假设——边界形状完全由数据决定，`k` 是唯一的旋钮：k 小 → 边界复杂、方差大；k 大 → 边界平滑、偏差大。
3. 代价有两个：预测时要和全部 14,520 个样本算距离（慢）；特征尺度必须先标准化，否则距离被大尺度特征主导。

## 5. 每个模型教会我们什么

1. **朴素贝叶斯**：准确率 63.47% 不比别人差，但 log loss 1.5052、ECE 0.2639——准确率高不等于概率可用。
2. **逻辑回归**：没有非线性、没有集成，但 log loss 0.6338 最低、ECE 0.0246 最低，覆盖 50% 时准确率 71.75% 最高。在 41 列、7,260 场的规模上，线性可加已经足够。
3. **随机森林**：准确率 64.02% 最高，但 log loss 0.6357、ECE 0.0310 都略逊。对比单棵树（0.8560），bagging 降方差的效果非常明显——但它买到的是准确率，不是概率质量。
4. **KNN**：准确率 62.75%，log loss 0.6396。它的意义是**提供一个「完全不做假设」的下界**——即使把边界形状完全交给数据，也还是停在同一个水平。这再次说明瓶颈不在模型的表达能力。

## 6. 讲的时候怎么说（每个模型一句话）

- **朴素贝叶斯**：「它假设特征互相独立，在我们的数据上明显不成立——准确率 63.47%，但 log loss 1.5052，概率被推到 0 和 1。」
- **逻辑回归**：「直接对概率建模、用交叉熵训练，概率天然可信。log loss 0.6338 最低，ECE 0.0246 最低。」
- **随机森林**：「bootstrap + 多树平均降方差。准确率 64.02% 最高，但概率略逊——加复杂度能换准确率，换不来概率质量。」
- **KNN**：「它完全不假设边界形状，只靠邻居投票。准确率 62.75%，还是停在同一个水平——**连最「自由」的模型也到不了更高。**」
