## 四、4 天内怎么把它变成"我的"

### 4.1 必做：三处实质性修改（每处 30–60 分钟）

**修改一：换掉一个核心实现**

`ablation.py` 里的 `metrics()` 是自己手写的。换成 `sklearn.metrics.log_loss`：

```python
from sklearn.metrics import log_loss, accuracy_score
# 原来手写的实现删掉，改成：
"logloss": float(log_loss(y, p, labels=[0, 1])),
"acc": float(accuracy_score(y, (p > 0.5).astype(int))),
```

**改完必须重跑，并确认数字只在小数第 6 位变化。** 如果变了，说明原来的实现有偏差——那就更值得写进报告。

**修改二：改一个超参网格并解释结果**

`four_models.py` 里的 `KNN_KS = [5, 15, 45, 135, 405]`。你自己加两个值（比如 75、270），重跑，然后回答："为什么最优点在 135 附近？"

**修改三：加一个你自己想要的指标**

比如 AUC：

```python
from sklearn.metrics import roc_auc_score
"AUC": float(roc_auc_score(y, p)),
```

加完你会发现**四个模型的 AUC 几乎一样**——这又是一个"准确率类指标分不出高低"的证据，可以直接放进 slide。

## 五、10 个必答题（导师最可能问的）

| # | 问题 | 答案要点 |
|---|---|---|
| 1 | 为什么主指标是 log loss 而不是准确率？ | 1,968 场抽样误差约 1pp；朴素贝叶斯准确率 63.47% 但 log loss 1.51。准确率分不出模型，log loss 能。 |
| 2 | 什么是校准？ECE 怎么算？ | 说 70% 的场次实际赢了多少。ECE = 各分箱 \|平均预测 − 实际频率\| 的场次加权和。 |
| 3 | 为什么四个模型准确率几乎一样？ | 特征已经榨干信息。换模型只带来 0.2–0.8pp，落在噪声内。 |
| 4 | 镜像扩增是什么，为什么必须做？ | 每场复制成两队互换的两行、标签翻转。不做的话模型学成"猜队 1"，因为队 1 胜率 55.9%。 |
| 5 | 逻辑回归为什么 `fit_intercept=False`？ | 对称化后截距的最优解恒为 0；有截距会破坏"换边概率互补"。 |
| 6 | `×1.15` 是什么？算不算调参调过头？ | 温度缩放，在**训练期五折**上选的，验证/测试集没参与。只有一个参数。 |
| 7 | KNN 为什么 k=5 的 log loss 会到 1.89？ | 概率只能是 0/0.2/…/1.0。给出 0 或 1 而猜错，单样本 log loss 超 6.9。 |
| 8 | 消融怎么保证可比？ | 同数据、同切分、同超参，**删列后重新训练**而不是置零（L2 对列数敏感）；全量配置复现 M2 差 3e-16。 |
| 9 | 训练期五折为什么要隔离 30 天？ | 相邻比赛有相关性（同一赛事、同一周），不留间隔会让留出折的信息漏进拟合。 |
| 10 | 测试集用了没有？用了几次？ | 用了一次（M2 62.76% / 0.6332）。评完锁定，不再用于任何调参。 |

**答不上来的题，就是你今天要补的题。**
