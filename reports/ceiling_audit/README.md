# 赛前预测准确率上限审计

审计日期：2026-11-25。目标是现有赛前信息对应的贝叶斯最优准确率，不预设 65%，不把现有模型的准确率或投票上限当成项目上限。

**结论：现有数据尚不能可靠识别真实上限，也不能支持“已经接近真实上限”的结论。** 两种邻域图方法对完整 M2 特征给出的测试期候选上界约为 68.5%–69.3%，验证期约为 70.6%–71.0%。这些只是把有限样本统计量代入渐近关系的结果，没有有限样本覆盖保证；本次已知真值校验明确揭示了它们可能严重低估上限。因此，不应将 69%、65% 或上述区间作为对外承诺的真实上限。

机器可读结果：[metrics.json](metrics.json)。各表示的完整计算表：[graph_diagnostics.csv](graph_diagnostics.csv)。新增程序：`scripts/audit_bayes_ceiling.py`；校验：`tests/test_audit_bayes_ceiling.py`。

## 1. 本次实际做了什么

- 重建完整数据期的赛前特征，训练期 7,260 场、验证期 1,968 场的 85 个共同字段与发布数据逐列核对通过。当天的结果只在当天全部打分后进入历史。
- 在验证期 1,968 场和测试期 2,159 场分别建立邻域图；图的构造不使用胜负标签，随后用标签计算相邻比赛的胜负差异。
- 使用完整 M2 的 41 维输入、同一输入的另一种可逆缩放、5 个实力特征的投影，以及已有全部数值型赛前输入加缺失标记（共 97 维）。不使用比赛 ID、日期、赛果或翻转标记作为距离输入。
- 使用最近邻的胜负差异率和最小生成树的跨标签边比例两种估计，并检查不同样本量、不同日期限制与特征表示的影响。
- 使用相同的特征构造真实上限已知的模拟赛果，检验估计方法。没有重训、替换正式模型，也没有把审计结果回流到调参。

41 维只是 M2 的信息表示；97 维也不包括完整历史序列、队伍身份等所有可能赛前信息。较少信息下的上界不能自动成为较多信息下的上界。

## 2. 数学对象与计算关系

固定允许使用的赛前信息 X、赛果 Y，以及要评估的比赛分布。定义

    eta(x) = P(Y=1 | X=x)
    A* = E[max(eta(X), 1-eta(X))]
    e* = 1-A* = E[min(eta(X), 1-eta(X))]

给定 X=x，选择队一的正确概率是 eta(x)，选择队二的是 1-eta(x)，所以逐点取最大值即得到 A*。这约束所有只使用 X 的分类规则，包含尚未训练出来的规则。

若能获得同一个条件状态 X 下两个独立赛果，它们的不同概率为

    R = E[2 eta(X)(1-eta(X))].

令 q(X)=min(eta(X),1-eta(X))，则 0<=q<=1/2。由 q<=2q(1-q) 得 e*<=R；又由 E[q²]>=(E[q])² 得 R<=2e*(1-e*)。解这两个不等式：

    (1-sqrt(1-2R))/2 <= e* <= R
    1-R <= A* <= (1+sqrt(1-2R))/2.

**即使 R 已被准确知道，上式通常仍是界，不是 A* 的精确值。**

在独立同分布和合适的正则性/局部收敛条件下，最近邻错误率、几何图跨标签边比例可以趋近这一类局部不一致量。这里采用

    R_NN = 不同标签的有向最近邻对数量 / n
    R_MST = 最小生成树上不同标签的边数 / n.

注意 MST 分母为 n，而非 n-1，对应其极限归一化。零距离边保留，最近邻排除自身，距离相同时采用与标签无关的固定随机顺序。

**有限样本的最近邻不等于相同 X，R_NN、R_MST 不等于真实 R。** 程序对超过 0.5 的值标为不合法，不通过裁剪制造看似有效的上界。

## 3. 实际候选上界

下表所有数字均为渐近公式的有限样本代入值，不是置信上界，也不是“真实上限”的点估计。

| 赛前输入表示 | 验证期最近邻 | 验证期生成树 | 测试期最近邻 | 测试期生成树 |
|---|---:|---:|---:|---:|
| 完整 M2 41 维，标准化 | 71.03% | 70.66% | 68.54% | 69.28% |
| 同样 41 维，可逆稳健缩放 | 69.33% | 69.06% | 68.29% | 68.79% |
| 5 个实力特征，信息减少 | 65.54% | 64.87% | 64.32% | 64.40% |
| 97 维数值赛前输入及缺失标记 | 69.52% | 69.26% | 67.25% | 68.54% |

标准化 M2 测试期最近邻差异率为 43.12%，生成树跨标签边为 919 条，919/2159=42.57%。代入上述公式即得到 68.54% 与 69.28%。

可逆缩放不会改变信息或真实 A*，却会改变有限样本的邻居和估计。97 维包含足以构造 M2 输入的信息，真实最优准确率不会因获得更多信息而下降；有限样本估计却下降，这是距离估计偏差的警示。不能为了接近某个预设数字挑选表示。

## 4. 已知真实上限的校验

固定测试期的特征，令 z(x) 为正式 M2 的对数赔率，用逻辑函数生成条件胜率：

    p(x) = sigmoid(c*z(x)).

选择 c，使这 2,159 个状态均匀加权的平均最优准确率恰好为指定值；然后每个状态按 p(x) 独立生成一次标签。模拟的 65% 和 80% 是检验工具的刻度，不是对项目真实上限的假设。每种随机标签实验重复 300 次。

完整 M2 标准化输入的结果：

| 模拟机制 | 已知真实上限 | 最近邻代入上界均值 | 生成树代入上界均值 |
|---|---:|---:|---:|
| 平缓的逻辑胜率 | 65.00% | 68.14% | 68.00% |
| 更陡的逻辑胜率 | 80.00% | 83.17% | 82.97% |
| 确定性边界 Y=1[z>=0] | 100.00% | 95.77% | 95.23% |
| 平滑但快速变化的胜率 | 80.00% | 56.43%* | 56.22%* |

最后一行用

    p(x) = sigmoid(c*sin(30*z(x)/sd(z)))

并选择 c 使真实上限恰好为 80%。没有加入额外信息，p 完全是相同特征的函数。它展示“连续/光滑”本身不足以给有限样本误差一个数值保证，必须限制变化速度。

* 最近邻 300 次中 109 次差异率大于 0.5，无法代入；其余 191 次全部错误地把上界放在 80% 以下。生成树 104 次不合法，其余 196 次全部低估。均值仅在合法代入结果中计算，不能视作完整分布或置信区间。

这些模拟不是说现实赛果遵循正弦函数，也不是推断现实上限有 80%。它们反驳的是“本样本上的该估计器对所有允许的胜率关系都能可靠给出上界”。

## 5. 数据为什么不够确定真实上限

完整 M2 输入下，测试期 2,159 场有 2,042 种不同特征向量，其中 2,001 种只出现一次。一个状态只观察到一次胜负，无法直接测得其真实胜率。

观测错误可能来自比赛条件下不可预测的波动，也可能来自模型尚未学到的特征关系。只凭当前模型错误率，不能分解这两者。多种模型都停在同一水平，也没有排除它们共同漏掉的结构。

完全相同的向量中有 16 组胜负冲突。按这些组事后取多数标签可以在原测试样本上得到 2,116/2,159=98.01%。这是查表的样本内最优值，不是未来泛化成绩；它既不能证明未来接近 98%，也不能给未来准确率一个 98% 的上界。此前讨论的硬投票上限同样只约束压缩后的表示。

此外，该项目有同队反复出现、同日及同赛事相关性、时间变化。独立同分布的几何图极限不能不加检查就应用为未来赛程的定理。

## 6. 现在能交付的结论，以及进一步需要什么

**可复核事实：** M2 在这批测试赛中 1,355/2,159=62.76%；按 199 个比赛日重采样 5,000 次得到描述性 95% 区间约 [60.30%,65.33%]。这不是项目上限区间，跨日期相关性仍未解决。

**当前上限分析：** 有限样本邻域图诊断给出完整 M2 表示下约 69% 的候选上界；由于缺少局部收敛/偏差控制，且已知真值校验有明确失败，不予认证。不应据此算“距上限只差 6 个点”。

**真实上限：** 本次未识别出可靠点估计或经验证的非平凡置信上界。100% 只是准确率恒真上界，不是项目的上限估计。

进一步获得可信上限，至少要明确：

1. 目标信息 X：41 维工程特征、全部历史，还是允许新增赛前名单/赛制等资料；目标时期和赛事构成也需固定。
2. 有证据支持的、可量化的结构假设：例如胜率在规定距离下的变化速度上限，或者经独立验证的生成模型。不能仅假定“M2 已正确估计全部真实胜率”，这会循环论证。
3. 足够密集的相近条件样本，以及与目标时间分布相符的独立检验；在这些条件下控制局部近似偏差和抽样误差，才可能给真实上限的置信界。

新增盲测可以确认锁定模型的性能；仅增加普通模型盲测不能自动证明全体模型的性能上限。若上述结构假设无法获得依据，继续计算也不能把未知的真实上限变成可靠数字。
