# M3（2/2）：孪生 LSTM 赛前胜负概率

## 结论

- **开发验证集 63.67% / log loss 0.6336**，相对冻结 M2 的 Δ log loss = -0.0002（LSTM − M2，正数表示更差），95% CI [-0.00474, +0.00432]  
  区间跨零，不能说它比 M2 更好或更差。
- 选中配置：<u>混合（+M2 线性项），N=10，隐层 16</u>，正式模型 lr=0.002、固定 14 轮，3 个种子取平均

## 协议

### 序列里有什么

- 每队取本场之前最近 N 场比赛，按时间从早到晚排列，不足 N 场补零并记录长度
- 每一步是那场历史比赛从本队视角看的信息：  
  胜负、地图比分差（除以总图数）、对手赛前 Elo − 本队赛前 Elo、本队赛前 Elo、距本场天数的对数、那场的赛事等级、那场名单与本队最近一次完整五人名单的重合度（含缺失标记）
- 每队另有当前赛前量：当前 Elo、历史场数的对数、是否有历史；本场赛事等级作为对称的比赛级输入
- Elo 在 `sequence_features.py` 内按天批量在线计算，K = 32（`reports/elo_validation.json` 选中值），不依赖各切分的特征 CSV
- 混合版另加 M2 的 41 列差值特征，经无偏置线性项进入分数

### 防泄漏规则

- **只用更早比赛日**：同一天的比赛先全部生成序列，当天结束后才把赛果、Elo、名单写入历史
- **本场的比分、胜负从不进入本场输入**，只在它成为之后比赛的历史时才被读取
- **不用 `bo_reported` / `bo`**：clean_v2 协议下赛制赛前未知
- **不用本场名单**：clean_v2 里本场五人名单是否完整与胜负强相关（只有一方名单完整时，这一方胜率约 65%–75%），属于赛后补录造成的泄漏；重合度改用本队更早的完整名单
- 训练与核验只读 2026-04-01 之前的比赛，**测试期标签未读取**，也没有生成测试集预测

### 结构与训练

- 两队共用一个 LSTM 编码器和一个打分头，分数 s = g(队一) − g(队二)（混合版再加 w·x），p = sigmoid(s)  
  交换两队后 s 精确变号，所以 <u>p(交换) = 1 − p 由结构保证</u>，无需镜像扩增
- 训练 7,260 场 / 开发验证 1,968 场；五折按天向前、间隔 30 天，OOF 覆盖 6,185 场
- 每折只在拟合侧训练：拟合侧最近 15% 的比赛日做早停集（之前隔 14 天），挑出轮数后在整个拟合侧按该轮数重训，再预测留出折；**留出折从不参与早停**
- **学习率也在拟合侧内层选**：每个（配置, 外层折）在内层早停集上比较 lr ∈ {0.002, 0.001}，取 3 个种子最佳早停 log loss 均值最低者（并列取 2e-3）
- 正式模型：lr 取选中配置 5 个外层折内层选择的多数；轮数取该 lr 在各折、各种子上内层早停轮数的中位数；在全部训练集上重训一次，val 只评估一次
- AdamW weight decay=0.01、dropout=0.2、batch=128；混合版线性项 L2 = 0.02
- 说明：早先一版草稿在一次冒烟测试后把 lr 固定为 1e-3，那次测试打印过外层留出折的 log loss；本次运行改为只用拟合侧内层验证重新选 lr，草稿的结果已作废

## 怎么读这个结果

- 仅序列版只看赛果序列和自算 Elo，信息量明显少于 M2 的 41 列（阵容、选手数据、地图池、图论实力）；它和 M2 的差距说明「从赛果序列里自动学」能补回多少
- 混合版等于「M2 线性项 + 序列修正」，它是否胜过 M2 才是序列模型有没有增量的直接检验
- 概率未做额外校准，报告同时给出 log loss 与 ECE；融合/校准留给 M3 stacking 与 M4，且只能在更早时间折上学习
- 权重 `models/m3_lstm/lstm.pt` 按 `.gitignore` 约定不进仓库，可由下方命令重建

## 复现

```bat
.venv\m3\Scripts\python.exe -B -m scripts.train_siamese_lstm train
.venv\m3\Scripts\python.exe -B -m scripts.train_siamese_lstm verify
```

- 训练设备 cuda，耗时约 6 分钟；torch 2.14.1+cu126
- 固定种子、确定性算法；预测统一在 CPU 上用保存的权重重算，`verify` 要求与 CSV 相差不超过 1e-6
- 给新比赛打分：`predict(bundle, matches_all, rows)`，`matches_all` 要包含 rows 之前的全部比赛
