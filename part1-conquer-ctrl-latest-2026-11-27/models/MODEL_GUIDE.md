# 三个模型介绍

三个模型都回答同一个问题：在地图已知、取得对应统计后，队1赢下这张地图的概率是多少？每张图用 71 个数字表示，全部是队1统计减队2统计。输入不包含赛果、比赛 ID 或队名。

## 朴素贝叶斯

它分别学习“队1赢”和“队1输”时，各项特征通常是什么样的，再比较新比赛的特征更像哪一类。

这里使用 GaussianNB，假设每项特征在每个类别内服从正态分布，并假设给定胜负后各特征相互独立。优点是简单、计算快；局限是本项目的多项统计高度相关，可能重复计算相近证据，导致过度自信。

代码在 `train_naive_bayes.py`。`var_smoothing=1.0` 用于方差平滑，保持与拆分前一致。不要因为准确率高就认定概率可靠，要同时查看 log loss。

## 逻辑回归

它给每个特征学习一个权重，把特征加权求和，再通过 sigmoid 函数转换成 0 到 1 之间的概率。权重不是手动指定，而是从训练数据中学习。

代码在 `train_logistic_regression.py`。`C=0.01` 控制正则化，较小的 C 更强地限制权重，降低过拟合风险。`fit_intercept=False` 不加固定偏置，配合双方差值和镜像训练。标准化使不同尺度的特征更容易共同参与训练。

它适合作为易解释的概率模型，但使用逻辑回归本身不能保证概率已经校准。

## 随机森林

一棵决策树通过一连串阈值判断来划分样本，例如“Rating 差是否大于某个值”。随机森林学习许多有差异的树，并平均各棵树的概率。

代码在 `train_random_forest.py`。`n_estimators=128` 表示 128 棵树；`min_samples_leaf=8` 限制叶子不要太小；`max_features='sqrt'` 让各次分裂只考虑随机抽取的部分特征。它可以表达非线性关系，但复杂度较高不意味着一定更好。

树通常不要求标准化。这里保留统一的 Pipeline，使整理前后流程和结果一致。

## 三个模型共同的步骤

`data_utils.py` 负责读数据、检查输入、构造差值、按日期切分、镜像扩增、训练预测和保存评估结果。先分训练与留出，再仅扩增训练侧。标准化也只从训练侧学习。

单独运行模型后，结果写入各自的 `results/模型名/`。准确率表示判断对了多少张图；log loss 和 Brier 同时考虑概率与真实结果，越低越好。已有 220 张地图留出成绩不能用来持续选择参数。
