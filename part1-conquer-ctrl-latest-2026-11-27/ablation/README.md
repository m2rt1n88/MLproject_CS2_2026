# 特征消融实验

目的：检查在其他特征仍存在时，一组特征是否提供额外帮助。模型固定为和三个模型实验一致的逻辑回归配置；每次删除一组列，重新训练，不改变模型参数，也不只是将该组置零。

## 五组特征

- Rating 综合评分：5 列，选手 Rating 的均值、总和、标准差、最大值和最小值。
- 队伍同图胜率：1 列。
- 交战表现：35 列，击杀、死亡、K/D、每回合击杀/死亡、伤害和爆头比例的汇总。
- 支援表现：20 列，每回合助攻、投掷物伤害、被队友救援和救援队友的汇总。
- 样本经验：10 列，统计覆盖的地图数和回合数。它反映统计样本量，不一定等同于选手完整职业经验。

合计 71 列，分组没有重复或遗漏。脚本遇到陌生列会报错，以免悄悄漏掉特征。

## 如何评估

只使用 2024-01-16 之前的 790 张训练地图。按比赛日分六段，第一段作为起始训练；后五段依次用更早日期拟合、在较晚日期留出。每次只扩增拟合侧，并在拟合侧拟合标准化。同一系列赛不会被拆开。

全部特征基线和五个删除配置使用同一组时间折，得到相同地图的训练期留出概率。将这些逐图损失汇总，而不是简单平均大小不同的折成绩。第一段没有留出预测，所以评分数量少于 790。

这里没有沿用旧数据的 30 天间隔，当前历史范围较短；使用严格的前后日期边界。它也不能解决原数据缺少特征快照时间的问题。

对每个删除配置计算相对全部特征基线的 Δ log loss，并按比赛日进行 2,000 次配对 bootstrap，给出 95% 区间。同一天的地图一起抽样。该区间没有校正多重比较，也没有建模跨日相关性，因此是探索性证据。


## 结果怎么读

结果在独立的 `ablation/results/` 中：

- `RESULTS.md`：中文结果摘要。
- `metrics.csv`：全部特征和删除五组后的总体成绩，以及相对基线的损失差和区间。
- `fold_metrics.csv`：各配置每一折的成绩。
- `predictions.csv`：按原始队伍方向对齐的训练期留出概率。
- `feature_groups.csv`：每个特征属于哪一组。
- `protocol.json`：数据指纹、日期边界和样本数量，便于核查。

Δ loss = 删除后的 log loss − 全部特征的 log loss：正值表示删除后更差，该组在当前组合中有帮助；负值表示删除后更好。区间跨零时，贡献方向的证据不明确。

相关特征可以互相替代，所以“去掉 Rating 影响小”不能推出“Rating 与胜负无关”。本实验也不会自动删列、改动模型或筛选最终方案。不能将这里的成绩直接与 `models/results` 的日期留出成绩作提升对比。
