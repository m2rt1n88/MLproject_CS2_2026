# M3 第二轮：与更多模型做堆叠

**结论：发现可保留的候选，暂不换主模型。** 扩展到 14 个底模配置（含 M2），测试 13 个搭档各三种组合、再加一个全体堆叠，共 40 个融合方案。只有四个通过训练期向前筛选。训练期选中的「M2 + 仅选手模型」在开发验证也比 M2 的 log loss 低，但差异区间跨零。全体堆叠有最低的开发验证 log loss，但并非事先选中的主候选，不能按这一次结果直接晋级。

| 方案 | 训练期向前检验（4,998 场）：准确率 / log loss | 开发验证（1,968 场）：准确率 / log loss |
|---|---:|---:|
| 原 M2（训练期仅作回顾参照） | 61.38% / 0.653290 | 63.26% / 0.633779 |
| 向前选参的 M2 | 61.38% / 0.654262 | 63.26% / 0.633779 |
| 仅缩放向前选参 M2 的概率 | 61.38% / 0.654004 | 63.26% / 0.634015 |
| **M2 + 仅选手模型：logit 堆叠（训练期选中）** | 61.48% / 0.653515 | 63.72% / 0.633215 |
| M2 + 仅选手模型：学习概率平均权重 | 61.50% / 0.653588 | 63.82% / 0.633717 |
| M2 + 外部历史 Elo 版 M2：50:50 平均 | 61.36% / 0.653564 | 63.62% / 0.633437 |
| 全体 logit 堆叠 | 61.44% / 0.653581 | **63.87% / 0.632622** |
| 外部历史 Elo 版 M2（单独，非堆叠） | 61.44% / 0.653236 | 63.82% / 0.633157 |

## 具体发现

- **仅选手版有补充价值，不代表它能独立替代 M2。** 仅选手版单独的开发验证为 61.38% / 0.648343。把它的胜率和 M2 堆叠后，训练期 4/4 折胜过向前选参的 M2，3/4 折胜过仅缩放 M2；开发验证净多猜对 9 场，log loss 差 −0.000564（按比赛日配对重采样 95% 区间 [−0.001987, +0.000983]）。它重用了 M2 中已有的部分信息，没有引入可核验的赛前首发名单。
- **全体堆叠没有真正依赖 14 个模型。** 用全训练期留出数据拟合后，非负 logit 系数主要给了外部历史 Elo 版 M2（0.8485）和仅选手版（0.2076）；随机森林（0.0108）和 P1 LightGBM（0.0035）只有很小的系数，其余为零。系数是对数几率的乘数，不是概率百分比。全体版较原 M2 净多猜对 12 场，损失差 −0.001158，95% 区间 [−0.002596, +0.000411]。开发验证反复使用过，且这里比较了许多方案；最低分不能当成独立确认。
- 外部历史版单独已到 0.633157；它与 M2 的等权融合虽然过了训练门槛，但没有比外部历史版本身更好。SVM、随机森林、AdaBoost、Bradley–Terry 等没有任何单独配对通过训练门槛。开发验证准确率最高的「M2 + SVM，50:50」为 64.08%，但其 log loss 为 0.640886，也未通过训练门槛。

## 方法与复现

- 底模配置：M2、同输入 LightGBM、M1 逻辑回归、线性 SVM、随机森林、AdaBoost、P0/P1 LightGBM、两版 Bradley–Terry、仅战队版、仅选手版、滚动 Elo、外部历史 Elo 版 M2。外部版沿用已保存的实验设置和本地数据库，外部赛果至少滞后 7 个日历日；该库不等同于逐条核验过发布时间的赛前数据。未引入神经模型，也未引入赔率。
- 三种配对方案为 50:50 概率平均、学习非负且总和为 1 的平均权重、学习非负 logit 系数（无截距）。推断时强制交换两队后概率互补；因此部分传统底模的独立分数与旧表直接输出原方向的分数略异。原 M2、同输入 LightGBM 和外部历史 Elo 版复算与其既有逐场预测一致。
- 第一折只提供第二层所需的历史留出预测；第 2–5 折的底模设置选择和融合拟合只用至少早 30 天的留出记录。入围须同时胜过向前 M2 与仅缩放 M2：合并 log loss 更低，且分别至少赢 3/4 折。只以训练结果选一个主候选；其余开发验证分数仅作诊断。两层均不使用最终测试集；主模型文件未改动。
- 复现：`.\.venv\m1\python.exe -B -m scripts.experiment_m3_stacking_broad select`，再以 `validate` 替换 `select`。需要现有 clean_v2 训练产物与 `references/csgopred/data/csgopred.db` 本地快照。
