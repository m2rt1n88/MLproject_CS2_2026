# 三个模型：朴素贝叶斯 / 逻辑回归 / 随机森林

**同一份数据、同一批 41 列特征、同一条时间切分、同一套镜像扩增与样本权重。**
唯一变化的是分类器本身。逻辑回归分支逐场复现发布版 M2（最大概率差 3.3e-16），说明三者的对照条件完全一致。

## 1. 结果

| 模型 | val 准确率 | val log loss | val Brier | val ECE | 覆盖 50% 时准确率 |
|---|---:|---:|---:|---:|---:|
| 朴素贝叶斯 | 63.47% | 1.5052 | 0.2980 | 0.2639 | 71.75% |
| 逻辑回归 | 63.26% | 0.6338 | 0.2218 | 0.0246 | 71.75% |
| 随机森林 | 64.02% | 0.6357 | 0.2226 | 0.0310 | 72.05% |
| *朴素贝叶斯（加平滑 var_smoothing=1）* | 60.62% | 0.6643 | 0.2360 | 0.0515 | 66.97% |

参照：每场都报 50% 的 log loss = **0.6931**。

## 2. 这三个数字最重要的一件事

- 准确率：63.47% / 63.26% / 64.02%，最大差 0.56 个百分点——**在 1,968 场的抽样误差内，分不出高低。**
- log loss：1.5052 / 0.6338 / 0.6357——**朴素贝叶斯是最差的 2.4 倍。**
- ECE：0.2639 / 0.0246 / 0.0310，朴素贝叶斯的校准误差是逻辑回归的 11 倍。

**所以：准确率这三列几乎没有信息量，log loss 和 ECE 才能把三个模型分开。**
这就是我们以 log loss 为主指标、并要求校准的全部理由。

## 3. 三个模型的原理（各三句）

### 朴素贝叶斯

1. 用贝叶斯公式：`P(胜 | 特征) ∝ P(特征 | 胜) × P(胜)`，谁的后验大概率高就判谁。
2. 它假设**各个特征在给定胜负之后互相独立**，所以只需要把每个特征的似然乘起来，参数量从指数级降到线性级。
3. 这个假设在真实数据上几乎一定不成立——我们的 41 列里有大量相关特征（Elo、图论实力、对手强度），它会把这些相关证据当成独立证据**重复累加**，于是概率被推到 0 或 1。

### 逻辑回归

1. 假设胜负的对数几率是特征的**线性函数**：`log(p/(1-p)) = w·x`，再用 sigmoid 压回 0–1。
2. 用极大似然（等价于最小化交叉熵）估计权重，加 L2 正则控制过拟合；我们的 `C=0.001` 是很强的正则。
3. 因为它直接对概率建模并用交叉熵训练，输出的概率天然比较可信——这正是它的 log loss 最好的原因。

### 随机森林

1. 训练很多棵决策树，每棵用**自助采样**（bootstrap）得到的不同数据子集，分裂时只看随机一部分特征。
2. 预测时把所有树的概率取平均。单棵树方差大（换个样本就变），平均之后方差被压下去——这就是 bagging。
3. 它擅长抓非线性与交互，但**平均概率并不保证校准**；在我们的数据上它的 log loss 略差于逻辑回归。

## 4. 每个模型教会我们什么

1. **朴素贝叶斯告诉我们「准确率高 ≠ 概率可用」。** 它准确率 63.47%，不比另外两个差，但 log loss 1.5052、ECE 0.2639：模型说 90% 的时候实际可能只赢 60%。**这种概率没法用来做决策。**
2. **逻辑回归告诉我们「简单模型可以是最好的概率模型」。** 它没有非线性、没有集成，但 log loss 0.6338 是三者最低，在 50% 覆盖率下准确率 71.75% 反而最高。在 41 列、7,260 场的规模上，线性可加已经足够。
3. **随机森林告诉我们「复杂度买得到准确率，买不到概率」。** 它准确率 64.02% 最高，但 log loss 0.6357、ECE 0.0310 都略差于逻辑回归。对比单棵决策树（log loss 0.8560），bagging 把方差压下去的效果非常明显。

## 5. 讲的时候怎么说（每个模型一句话）

- **朴素贝叶斯**：「它假设特征互相独立，这个假设在我们的数据上明显不成立——准确率还有 63.47%，但 log loss 是 1.5052，概率被推到了 0 和 1。它是我们主指标选择的证据。」
- **逻辑回归**：「它直接对概率建模，用交叉熵训练，所以概率天然可信。log loss 0.6338 是三者最好，ECE 只有 0.0246。正式模型选它。」
- **随机森林**：「它用 bootstrap + 多树平均降低方差。准确率 64.02% 最高，但概率略逊。它证明了一件事——**加复杂度能换准确率，换不来概率质量**。」
