### 第 2 站：每个特征值多少钱

📁 `02-特征消融/`

| 文件 | 是什么 |
|---|---|
| `ablation.py` | 把 41 个特征分成 8 组，每次删一组重新训练 |
| `ABLATION.md` | 生成的结果表 |
| `metrics.csv` | 17 个配置 × 2 个口径的原始指标 |

**要理解的核心**：**消融 = 拆零件**。想知道哪个零件有用，就一个个拔掉看机器还转不转。

**三个必须守的规矩**：
1. 只改一个变量（同数据、同切分、同超参）
2. 必须**重新训练**，不能只是把列置零（L2 正则对列数敏感）
3. 在 OOF / val 上比，**不碰测试集**

**关键结果**：

| 删掉的组 | Δ log loss | 显著？ | 怎么讲 |
|---|---:|---|---|
| 图论实力 | +0.0054 | ✅ | 唯一真正的大项 |
| 阵容 | +0.0025 | ✅ | 第二重要 |
| Elo 差 | **0.0000** | ❌ | 被图论实力覆盖了 |
| 近期状态 | −0.0011 | ✅ | 删掉反而更好，是噪声 |

**最容易被问的一句**：「Elo 删了不掉分，是不是 Elo 没用？」
→ 不是。只留 Elo 两列还有 59.76%，远高于瞎猜的 50% 和"永远猜队1"的 55.9%。是**在已有图论实力的条件下，Elo 没有额外信息**。

### 第 3 站：分数可不可信

📁 `03-校准与选择性预测/`

| 文件 | 是什么 |
|---|---|
| `m4_report.py` | 生成 M4 报告（校准、分层、选择性预测、置信区间） |
| `M4.md` | 正式报告 |
| `selective_report.py` | 临时查看工具（对任意预测文件快速跑一张覆盖率表） |

**要理解的核心**：准确率不管你"说得多有把握"，log loss 和 ECE 管。

三个概念，讲之前必须自己说顺：

1. **log loss**：你对正确答案给了多少概率。说 95% 而猜对，罚 0.05；说 51% 而猜对，罚 0.67。**猜错还嘴硬，罚最狠。** 瞎猜是 0.6931，你们 0.6332。
2. **ECE**：说 70% 的那些场次，实际赢了多少，差多少个百分点。你们 1.85 个百分点。
3. **覆盖率**：只在有把握时下判断。`|p−0.5| ≥ 0.10` 的场次留下 = 51.2% 覆盖，这些场次准确率 71.25%。

**报告里的三处自我保护**：
- 校准器只在训练期留出（OOF）上拟合，测试集不参与。
- 置信区间全部用 bootstrap。
- "70% 只在选择性预测口径下成立"这句话写进了正文。

### 第 4 站：别的模型行不行

📁 `04-两个基础模型/`

| 文件 | 是什么 |
|---|---|
| `train_basic_models.py` | 高斯朴素贝叶斯 + 单棵决策树 + 同 41 列随机森林对照 |
| `BASIC_MODELS.md` | 报告 |
| `metrics.csv` | 原始指标 |

**课内出处**（照着讲，别说错）：
- 朴素贝叶斯 → 大纲 **§2b "Bayes' rule & MAP classifiers"**（第二章第四节讲）
- 决策树 → 大纲没有单列，它是 **§5d random forests** 的组成单元。**定位成"拆开随机森林的工具"，不要说成"课内模型"。**

**两个教学点**：

1. **决策树：教科书级过拟合**
   深度 2 → 不限：训练集 60.2% → 68.4%，验证集 63.1% → 57.7%，log loss 0.65 → 0.86。

2. **朴素贝叶斯：准确率会骗人**
   `var_smoothing=1e-6` 时准确率 **63.57%**，比正式模型 M2 的 63.26% 还高。
   但 log loss 是 **1.4364**（M2 的 2.3 倍），ECE 0.26。
   → **这是"为什么主指标必须用 log loss"最硬的一条证据。**

3. **bagging 值多少**：同 41 列、同叶子下界，单棵树 0.8560 → 128 棵树的森林 0.6357，降 0.22。

## 自测：五个可能被问到的问题

1. **「你们准确率多少？」**
   → 全场 62.76%。但单场比赛不可预测，2,159 场里 1 个百分点的波动都是噪声。我们交付的是校准良好的概率：ECE 0.0185。

2. **「为什么不用准确率当主指标？」**
   → 朴素贝叶斯的例子最直接：准确率 63.57% 比正式模型还高，但 log loss 1.44。准确率不管你说得多有把握。

3. **「70% 是怎么来的？」**
   → 放弃 48.8% 没把握的场次，剩下 51.2% 的准确率是 71.25%。全场 70% 不可达——按分区加权，Tier 1 得做到 80.3%。

4. **「哪些特征有用？」**
   → 逐组消融 + 配对 bootstrap：图论实力 +0.0054、阵容 +0.0025 显著；Elo 删掉不掉分（被图论实力覆盖）；近期状态和地图池删掉反而更好。

5. **「有没有可能过拟合或者泄漏？」**
   → 三重保护：特征只用本场之前的数据（同日先算完再更新）；时间切分不随机；测试集只评一次。另外重建的 train/val 特征与发布版 85 列逐列一致（最大概率差 3e-16），说明管线没被改动。
