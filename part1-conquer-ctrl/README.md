## 四项工作的要点

### 1. 最终测试集评估（此前一直没跑）

- 测试期特征必须用**全部 11,387 场**在线重建后切片。只喂测试期会让每支队的 Elo 从 1500 重新开始，结果全错。
- 脚本内含硬检查：重建后的 train/val 特征与仓库里发布的版本**逐列比对（85 列）**，不一致直接报错退出。实测最大概率差 **3.3e-16**。
- 用冻结权重预测，**不重训**。

### 2. 特征消融（分工表里写了但此前未做）

- 41 列按语义分 8 组（Elo / 近期状态 / 阵容 / 地图池 / 历史交手 / 图论实力 / 经验 / 赛制交互），逐组删除后**重新训练**。
- 不是把列置零：`C=0.001` 的 L2 正则对列数敏感，置零和删列不可比。
- 全量配置复现发布版 M2 的最大概率差 3.3e-16，说明对照有效。
- 显著性用**配对 bootstrap**（2000 次，按同一批比赛重采样）。

### 3. M4 校准与选择性预测（此前完全空白）

- 校准器（Platt / isotonic）**只在训练期留出上拟合、在验证集上评估**，测试集不参与任何拟合。
- 结论：**不需要额外校准器**。两者的 Δ log loss 置信区间都跨零。
- 分层报 Tier 1 / 2 / 3（测试集 65.18% / 62.04% / 54.74%），避免用总分掩盖低级别赛事的不可预测性。

### 4. 两个课内基础模型

- **朴素贝叶斯**：准确率 63.57%，比 M2 还高，但 log loss 1.4364（M2 的 2.3 倍）。
  条件独立假设把高度相关的特征当成独立证据重复累加，概率被推到 0/1。
  **这是「主指标必须用 log loss 而不是准确率」最直接的一条证据。**
- **决策树**：深度从 2 加到不限，训练集准确率 60.2%→68.4%，验证集 63.1%→57.7%。
  与同 41 列、同叶子下界的随机森林对照（0.8560 → 0.6357），量化了 bagging 的贡献。

## 需要全组确认的两件事

### ① README 里「70% 是全场准确率目标」这一句建议修改

按测试集实际分区构成加权：

- 若 Tier 3 维持 54.74%、Tier 2 维持 62.04%，**Tier 1 需要做到 80.3%**（现在 65.18%）
- 若 Tier 1 / 2 同步提升，两者都要到 **71.8%**

而博彩市场在拥有赔率、伤病、转会信息的前提下也只有约 65–68%。**全场 70% 在本数据上不可达**，写成目标会在答辩时被直接质疑。

建议改为：

> 全场准确率 **62.76%**（log loss 0.6332，ECE 0.0185）。**70% 是选择性预测下的条件准确率**：放弃 48.8% 的场次后，剩余 51.2% 的准确率为 **71.25%**。

`reports/M2.md` 里已经写了「不能据此宣称已达到 70%」，目前两处口径不一致。

### ② 测试集已经用掉了

2,159 场的数字从现在起就是最终数字。**后续任何调参、换特征、选模型都不能再看这批比赛**，否则它会退化成验证集，报告的可信度归零。

需要改模型时请用 `m2_val.csv`（1,968 场）和 `m2_oof.csv`（6,185 场），改完只在最后再评一次测试集。
